# Security policy

Please do not report vulnerabilities in a public issue. Use GitHub's private
security advisory feature for this repository instead.

Never include Circle passwords, phone numbers, authorization values, user or
child tokens, watch identifiers, child names, coordinates, packet captures, or
Home Assistant storage files in a report. Replace sensitive fields with their
type and length when context is needed.

This project uses an undocumented third-party cloud API. Vendor-side security
issues should also be reported responsibly to the vendor.
